# บันทึกโปรเจกต์ในแชท — รุ่นทดลอง 0.3.1

ช่วย AI สรุปความคืบหน้า งานปัจจุบัน งานถัดไป และไอเดียจากบทสนทนาเดียวกัน
เป็นปลั๊กอินแบบ skill ใช้ AI ของแชท ไม่มีเซิร์ฟเวอร์หรือ API ภายนอกสำหรับการติดตาม

## ทดลองได้สองแบบ

### ใช้ข้อความตั้งต้นกับ AI ในแชท
เปิดไฟล์ `PROMPT-TH.md` แล้วคัดลอกข้อความทั้งหมดไปเริ่มแชท
จากนั้นบอกชื่อโปรเจกต์ เป้าหมาย และสิ่งที่ทำไปแล้ว
วิธีนี้ใช้เป็นคำสั่งตั้งต้นในแชท ไม่ได้ติดตั้งปลั๊กอิน และผลลัพธ์ขึ้นกับ AI ที่ใช้

### ติดตั้งปลั๊กอินผ่าน repo marketplace ในแอปที่รองรับ
แพ็กเกจนี้มี `.agents/plugins/marketplace.json` และปลั๊กอินใน `plugins/chat-project-memory`

ถ้ามี Codex CLI และแอป desktop ที่รองรับ local marketplaces:
1. แตก ZIP และใช้โฟลเดอร์นี้เป็น marketplace root
2. ลงทะเบียนโฟลเดอร์ด้วย `codex plugin marketplace add <absolute-path-to-this-folder>`
3. เปิดแอป desktop ใหม่ ไปที่ Plugins เลือกแหล่ง Project Memory Trial และติดตั้ง
4. เปิดแชท แล้วพิมพ์ @ เลือก “บันทึกโปรเจกต์ในแชท”

ผู้ทดลองสามารถใช้ `codex plugin marketplace add samut2jumpol-crypto/MEMORY_ADDON_AI`
GitHub repo marketplaces ไม่ใช่รายการปลั๊กอินสาธารณะของ ChatGPT และการรองรับต่างกันตามแอป

คู่มือ OpenAI:
- https://developers.openai.com/plugins/build/plugins
- https://learn.chatgpt.com/docs/build-plugins

## เริ่มใช้งาน

ตัวอย่างสมมติ:
“โปรเจกต์เกม Roblox แนวเก็บเหรียญ เป้าหมายแรกคือให้เดินเก็บเหรียญได้ ตอนนี้ยังไม่ได้เริ่ม”

คุยเรื่องงานตามปกติได้ เมื่อมีความคืบหน้า AI จะปรับสถานะจากบริบท
ถ้าน่าจะทำเสร็จแต่ยังไม่ชัด จะถามยืนยันสั้น ๆ
“อยากเพิ่มระบบสัตว์เลี้ยงทีหลัง” จะถูกเก็บเป็นไอเดีย
“เอาระบบสัตว์เลี้ยงมาเริ่มทำ” จะย้ายเป็นงานที่วางแผนไว้
“ทำถึงไหนแล้ว” จะได้ checkpoint ล่าสุด

## ข้อจำกัดที่ผู้ทดลองควรรู้
- ทำงานเมื่อได้รับข้อความและ skill ถูกเลือกหรือมีผลอยู่ ไม่เฝ้าดูงานเบื้องหลัง
- ไม่เห็น Roblox Studio หรือโปรเจกต์นอกแชทโดยอัตโนมัติ
- ใช้บริบทที่ AI มองเห็นในแชท จึงไม่รับประกันว่าจะจำประวัติยาวทั้งหมด
- เมื่อเริ่มแชทใหม่ ให้คัดลอก checkpoint ล่าสุดไปด้วย
- คำตอบจาก AI อาจคลาดเคลื่อน ตรวจสถานะสำคัญก่อนนำไปใช้
- ยังไม่ได้ทดสอบการสนทนาจริงครบทุกกรณีในทุกแอป
